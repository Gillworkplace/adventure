# Adventure v2

这是一个在 Adventure 游戏中为骰子和卡牌的下一步选择给出推荐的 Web 应用。支持三种模式：读取所连接游戏画面的**辅助（Assist）**、手动输入状态的**手动**、处理所按下骰子·卡牌结果的**自动**模式。实际游戏由用户亲自操作。

辅助模式的**语音引导**支持韩语·英语·日语·中文以及女声·男声。所选语音可在确认体积后下载，并支持在浏览器中保存与删除。引导语音是使用 Gemini 3.8 Flash TTS 预先生成的 AI 语音。

## 模型选择

| 模型 | 计算方式 | 平均成绩 |
| --- | --- | ---: |
| **VELA · v4.2** | 用 CPU 展开后续局面来评估行动 | 约 1,877 分 |
| **X36 · G3** | 用 CPU 或 GPU 多次模拟来比较各选择 | 约 1,860 分 |

平均成绩是在不同评估中取得的参考值。计算时间会随设备和游戏局势而变化。

VELA 首次使用时会加载约 **68MB** 的模型。在网站上，只要同意保存到浏览器，下次访问起就会复用已保存的模型。确认最新模型信息时，会先清理不兼容的旧版本存储数据。本地运行时直接使用项目内的模型文件，不会额外保存到浏览器。

VELA 的各行动评估值表示该选择的有利程度。预期最终分数是持续遵循所选模型推荐时的预测值。VELA v4.2 通过专为 Hinge 训练的预测器提供预期最终分数。游戏结束后会显示实际分数。取消模型选择后，也可以在无推荐的状态下使用。

## 在我的电脑上运行

只要有 **Node.js 22 或更高版本**，无需额外安装依赖或构建即可运行。

1. 下载项目并解压。
2. **如需使用 VELA**，请另行准备 VELA-v4.2 模型文件 `model.bin.gz`。发布的模型可从 GitHub 项目的 **Releases** 页面下载。**不要解压**，直接放入项目的 `public/models/vela-v4.2/` 文件夹。最终文件路径为 `public/models/vela-v4.2/model.bin.gz`。如果只使用 X36 · G3，可以跳过这一步。
3. 在项目文件夹中打开终端，运行以下命令：

   ```sh
   node scripts/serve.mjs
   ```

4. 在浏览器中打开 **[http://127.0.0.1:4173/](http://127.0.0.1:4173/)**。也可以通过 `PORT` 环境变量指定端口。

也可以用 `npm start` 运行。使用期间请保持终端开启，结束时按 `Ctrl+C`。不支持直接双击 `index.html` 的 `file://` 方式打开。

### 一键启动（Windows）

双击项目根目录的脚本即可自动启动服务器并打开浏览器，模型选择窗口中对应选项已预选，点“다음（下一步）”确认即可：

- **`start-vela.bat`** — 以 VELA · v4.2 为默认选择启动（缺少 `model.bin.gz` 时会先提示）
- **`start-x36.bat`** — 以 X36 · G3 为默认选择启动

脚本会自动复用已在运行的服务器；也可以用 `PORT` 环境变量指定端口。等价的手动写法是在地址后加参数：`http://127.0.0.1:4173/?model=vela` 或 `?model=x36`。

## 使用帮助
