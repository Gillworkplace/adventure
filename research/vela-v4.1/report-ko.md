# FULL48 共享结构压缩·手牌·牌堆交互研究结果

2026-09-27 · 已完成实际运行 · 未修改原始/生产文件

## 1. 结论

**37.68 MiB 最终候选 `quant_q6_k64_t12` 的非劣效性判定：未达成。** 在独立原始得分评估中未能满足 0.1% 非劣效性标准。因此不将其提升为原始 FULL48 的替代模型。最终 90,000 局 paired 游戏中，原始模型 1878.0848 分，候选模型 1876.5108 分，差值 -1.5740 分，95% CI [-2.917, -0.231]。允许损失为 1.8781 分，而观测差值的 CI 完全小于 0。判定的含义是**允许损失边界与 CI 重叠，无法确认非劣效性**。

以低秩时间结构和共享高阶手牌模式缩减大表的方向得到了支持。但仅凭较低的矩阵误差、较少的动作不一致以及正协同的稀疏性，并不能确定策略得分得以保持。下一轮设计将优先考虑在以量化保持结构的同时，更好地拟合对动作差异敏感的高阶残差。

## 2. 比较条件与独立性

以既有 interaction spectrum 研究（原始研究资料）中的 H24 五张手牌重建误差（pair 13.0639 → triple 5.1577 → 四阶 2.5144）为出发点。该结果是高阶信息必要的依据，而不是必须单独存储高阶系数的结论。此前改为 r=1 的 1,024 个状态未在本次最终评估中重复使用。

基准为原始存储的 FULL48 cap5 + v4 2-step expectimax + DeckPotential 0.6。保持了既有在线区间的真实不放回牌堆转移。存储表为 tier0 FP32 与 tier1~5 int16 delta/32，合计 45,871,677,316 bytes（42.721 GiB）。压缩针对 FULL48 的每个 r,b,p 以及全部 80,730 个多重集手牌，未将小 cap2 游戏或 W± 作为训练目标。

## 3. 实现的压缩结构

`Fhat = B + low_q + G + S`。B 在所有位置·bonus·时间上直接存储原始 FP32 值。low_q 仅对 anchored singleton/pair 系数做时间轴分解。重复卡牌会精确统计副本对，因此同一 class 的 pair 数为 C(m,2)。未将位置合并成桶。

G 是 `a(r,b,p)^T phi(H)` 的共享手牌 embedding 模型。它以全部 80,730 个多重集作为输入，因此能够表达宽广的高阶·非线性手牌效应。训练目标是低秩重建后剩余的最终手牌残差。并未实现小型 MLP 或 semantic HOFM 本身。针对 q4/q8/q6 各低秩模型分别训练了 G。以 784 个层/位置行构造 basis，并用 1,024 个手牌拟合所有位置·时间的系数。部分小 K 模型是经 64 维联合回归后截断得到的，并不保证是该 K 下的最优回归。

S 在训练用游戏的近邻动作相关 leaf 的 466,521 次查询、452,619 个唯一 key 上存储 G 之后的残差。其优先级是残差·查询次数·root action gap 的代理指标，并非精确的动作敏感度优化。不会重新累加单个 interaction 系数。按模式规则归组的例外模型未包含在本次实现中。

量化模型将 A/phi/G 分别以对称 int16 + scale 存储，运行期间也保持 int16 数组。并不是把完整 FP32 模型展开到 RAM 的方式。攻击型在 A 上应用追加 pair 轴 rank J=16。名称中的 q 是低秩时间 rank，k 是手牌 basis 数，t 是 G 的时间 rank，s 是例外 MiB。

## 6. 最终冻结与独立 9 万局

在 40 MiB 以下且初筛评估平均损失不超过 5 分的模型中，选择了诊断 Q 损失最小的一个候选。选择规则与模型/可执行文件的 SHA256 在打开最终数据之前已冻结。候选为 `quant_q6_k64_t12`，实际模型 39,512,548 bytes = 37.6821 MiB。冻结记录（原始研究资料）。

| 指标 | 原始得分：主判定 | Martingale CV：辅助判定 |
|---|---|---|
| 原始平均值 | 1878.0848 | 1878.3545 |
| 压缩平均值 | 1876.5108 | 1876.5089 |
| 差值 | -1.5740 | -1.8456 |
| paired SD | 205.5132 | 38.4289 |
| 95% CI | [-2.917, -0.231] | [-2.097, -1.595] |
| 0.1% 判定 | 未达成 | 按 CI 标准未达成 |

CV 是一种条件均值 0 校正：累积真实下一状态的 Phi 与真实转移整体期望 Phi 之差，并从得分中扣除。Phi 为固定的原始 FULL48 与既有 deck potential，系数为 1。未用最终 seed 训练 Phi 或系数。它不参与策略选择与 RNG，也没有额外 rollout。若原始得分主判定失败，即使辅助 CV 良好也不改为成功。仅最终 CV 评估读取原始表是评估工具的成本，并不是压缩策略的部署需求。

## 7. 假设 C·D：分离比较在线连锁与牌堆

公共 leaf 为 `quant_q8_k32_t16`（36.01 MiB）。free_gap 在 root 第 1·2 名差距小于 1 分时，以无 draw 的免费连锁最多补充 512 个节点。free_hand5 则在 root 手牌为 5 张时也开启。true3/ iid3 以相同的 gap 条件和相同的状态优先级，对最多 24 个首个后续状态多计算一层。所有 chance 结果都纳入平均，未被选择的结果按原有 2-step 值评估。

既有的 free 两种情形按动作顺序使用全局 512 节点预算，计算可能集中在靠前的动作上。代码审查后追加了单独的 `online_free_balanced` 对照。它在相同 gap 条件下，对每个不同动作使用 floor(512/动作数) 预算和独立缓存。这并不是连各动作内部分支顺序效应都已消除的最优预算分配。追加对照是不改变冻结压缩候选与最终 seed 的探索性 1 万局，已另行记录在 ONLINE_BUDGET_CONTROL_ADDENDUM.md 中。

true3 与 iid3 仅把追加最后一次 draw 的手牌价值分布换为真实牌堆/IID。既有的前 2 层使用真实牌堆，既有 scalar DeckPotential 为公共项。因此不再重复累加此前已计算过的 draw 校正。该对照既不是全区间完整的不放回 Bellman 差异，也不是训练得到的长期 hand×deck tail 模型。

两种情形的相同预算意味着最多 24 个追加状态以及相同的深度限制。IID 在最后一次抽牌时总是评估全部 22 个 class，而真实牌堆只评估剩余 class，因此实际的 leaf 查询次数与运行时间并不相同。这一差异按原样记录在成本表中。

## 8. FULL100 扩展

从 r48 的原始 FP32 cap5 snapshot 出发，用相同的 solver 接续计算了 r49~100。未将 quantized 层用作重启输入，保持了原有的 Bellman 迭代终止条件 residual<0.001。每层的全部 80,730 个手牌在 solver RAM 中计算，低秩整体与 1,536 个手牌以流式存储。保留了 r64/80/96/100 的完整 FP32 检查点。生成耗时 1,372.74 秒（6 threads，与其他研究任务存在部分争用）。由于未生成原始 FULL100 完整文件与原始 FULL100 策略评估，未验证 FULL100 本身的压缩非劣效性。

每隔 4 个检查点校验一次：256 个位置/bonus 行的低秩 276 个值与抽样 1,536 个 delta 均与存储流一致。FULL100 压缩模型另行 10,000 次 C++/Python 查询的最大差值为 0.000271 分。这是对原始 snapshot 接续计算的存储一致性与执行实现的验证，该结果本身并不能证明 FULL100 策略得分得以保持。

FULL100 模型为 34.33 MiB，迁移了从 FULL48 q8 获得的手牌 basis，但位置·时间系数重新拟合到 0~100 的目标值。即便在更高的 horizon 下存储量增长也不大，但相同 q 下 FULL100 的系数误差更大。与 FULL48 基准的 1 万局差异同时包含 horizon 变更与压缩两个因素。不将此实验解读为纯压缩效果。

相同 q8/K32/t8 维度的 FULL48 压缩模型与 FULL100 压缩模型直接配对比较的差值为 -2.3192 分，nominal 95% CI [-6.141, +1.502]。该比较同样同时改变了时间范围与 factor 重训练，因此不将其归因于单方面效果。

## 11. 最终得到强化的假设与下一步研究的边界

1. **时间共享结构确实存在，但小 q 的局部精度是另一个问题。** 不用平均能量掩盖 q4 的大最大误差。将位置分辨率保持 + int16 q6~8 作为优先比较对象。
2. **共享高阶残差是必需的。** G 大幅降低了仅保留 pair 的损失。下一轮训练目标不仅是值的全局 MSE，还包括相近动作之间的 Q 差异，并集中处理大手牌下残留的误差。
3. **例外的稀疏性尚未确认成立。** 本次基于 dev leaf 的 S4 没有明确收益。没有理由回到原先按 interaction 大小排序存储的方式。
4. **免费连锁·追加概率展开必须结合真实 whole-game 结果与成本一起评估。** 不假设把表已反映的免费使用再次 max 的计算总是有益。
5. **手牌×牌堆条件效应存在。** 应精确区分既有搜索边界之后残留的效应，并将访问概率·动作 gap·残差信号用于追加计算的选择。不把 variance/top-card mass 直接加到期望得分上。
6. **6~10 MiB 尚不是已达成的目标。** 在没有能降低追加 pair 轴 factorization 损失的新训练/局部补偿之前，不将其采纳为主力方案。
7. **FULL100 容量扩展可行，但性能保持的证明仍有待完成。** 不将相同 rank 已足够这一结论泛化，需要 FULL100 自身的原始策略基准。

未实现的范围包括：semantic 组特性的单独 ablation、单独的小型 MLP/HOFM、基于区间规则的 S、训练得到的 hand×deck tail residual、FULL100 完整原始策略、通过独立最终游戏同时验证多个在线候选。不将这些标示为已执行。可以基于当前结果设计下一轮研究，但未针对最终游戏对本冻结候选重新调优。

后续训练的具体优先级是：(a) 将各位置的回归样本按重复张数模式分层，并把罕见的纯重复手牌也纳入 anchor；(b) 在全局价值 MSE 之外同时学习竞争动作之间的相对 Q 差异；(c) 向 p=2827 这类局部时间曲线分配小型低秩残差或追加时间 basis。这些是尚待进一步验证的假设，不计入本次最终模型已测得的改进。

## 12. 论文·资料与复现

以下资料是设计方向的依据，并不是在 VELA 中证明了特定 MiB 得分保持的资料。

- [Higher-Order Factorization Machines](https://papers.nips.cc/paper/6144-higher-order-factorization-machines.pdf)：高阶交互的共享表示。未将原有的 distinct-feature kernel 直接套用到重复卡牌上。
- [Tensor Low-rank Approximation of Finite-horizon Value Functions](https://arxiv.org/abs/2405.17628)：包含时间轴的价值张量分解。实际所需的 rank 由本次全量分析测得。
- [The Value Equivalence Principle](https://arxiv.org/abs/2011.03506)：保持对规划有用的价值信息的方向。不主张本次近似满足论文的精确等价条件。
- [Value-Aware Loss Function](https://proceedings.mlr.press/v54/farahmand17a.html)：对规划价值敏感的训练目标的依据。后续研究将考察动作 Q 差异的加权。
- [Finding Structure with Randomness](https://authors.library.caltech.edu/records/hy0mc-xmn26)：大矩阵共享 subspace 的提取。低秩使用全量时间 Gram，高阶使用抽样行加以区分。
- [AIVAT](https://arxiv.org/abs/1612.06915)：通过固定价值启发式的均值 0 校正降低评估方差。本研究仅使用了 chance martingale CV。
